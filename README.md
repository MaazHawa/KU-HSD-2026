# Gunter's Forge

Mobile storefront for Gunter's blacksmith shop in Mautern.

## Features
- Order a Sword, Plate Armor, Chain Mail, or Cooking Pot
- Every order gets an ID (GF-1001, ...), a queue position and an estimated wait
- Workshop view for Gunter: advance orders, see the full list
- Supply tracker: starting an order uses up iron, coal, and leather. Warns when low. Blocks orders he cannot fill

## Run it
Open `index.html` in a browser. Data is saved in the browser's localStorage.
